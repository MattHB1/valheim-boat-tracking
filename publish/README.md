# BoatTracking

Lost another longship? Hold **E** on a boat to name it, then find it on the map from anywhere - including on a dedicated server.

## Install

**Server and every client need this mod.**

1. Open r2modman / Thunderstore Mod Manager → Valheim.
2. Online → search `DevDonkey-BoatTracking` → Install (needs **BepInExPack_Valheim**).
3. Install the same package on your dedicated server profile.
4. Launch through the mod manager.

Manual: put `BoatTracking.dll` in `BepInEx/plugins/` on server and clients.

## Use

- Look at a ship (not a chest) and **hold E** → rename.
- Tap E still boards / steers as normal.
- Named ships (and optionally unnamed ones) show on the minimap and world map with a boat icon.

## Notes

- Vanilla Raft, Karve, and Longship.
- Empty name falls back to the ship type label.
- Other mods: [DevDonkey on Thunderstore](https://thunderstore.io/c/valheim/p/DevDonkey/)
