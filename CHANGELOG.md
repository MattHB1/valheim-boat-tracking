# Changelog

## 1.0.0

- Hold E on a ship to rename it (tap E still boards / steers).
- Dedicated server syncs ship positions and names so map markers work from anywhere.
- Map markers for Raft, Karve, Longship, and Drakkar.
- Custom name labels on the full map.
- Protocol check warns in-game when client and server builds do not match.
- Install on **server and clients** for multiplayer.
